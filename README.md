Projetos --- Digital College

📚 Sobre o projeto

Este repositório reúne três projetos de desenvolvimento web
realizados para fins acadêmicos, como parte dos estudos no curso da
Digital College.

Os projetos foram desenvolvidos com foco na prática de HTML e CSS,
trabalhando principalmente estruturação de páginas, organização de
conteúdo, criação de layouts, tipografia, cores, espaçamentos,
componentes visuais e responsividade.

Observação: Estes projetos têm finalidade exclusivamente acadêmica
e foram desenvolvidos para estudo e prática pessoal.

------------------------------------------------------------------------------------

🟢 Nível 1 --- Nexa Digital

Sobre o projeto

O **Nexa Digital** é uma página institucional criada para uma empresa fictícia
que oferece soluções para negócios.

A proposta do projeto foi desenvolver uma página simples, organizada e
visualmente agradável, apresentando os principais serviços oferecidos
pela empresa.

-----**Principais seções**-----

Cabeçalho com navegação;

Seção principal (Hero);

Apresentação da empresa;

Seção de serviços;

Desenvolvimento Web;

Marketing Digital;

Design e Identidade;

Análise de Dados;

Chamada para contato.

Objetivo acadêmico

Praticar a construção de uma landing page institucional, trabalhando
a estrutura semântica do HTML e a estilização dos elementos utilizando
CSS.

----------------------------------------------------------------------------------

🔵 Nível 2 --- CodeUp

Sobre o projeto

O **CodeUp** é uma plataforma fictícia de cursos online. O projeto
apresenta uma página de planos de assinatura, permitindo visualizar
diferentes opções para os usuários.

A página foi criada com foco na organização visual das informações e na
apresentação de diferentes planos de forma clara.

-----**Principais seções**-----

Cabeçalho com navegação;

Apresentação dos planos;

Plano Básico;

Plano Pro;

Plano Premium;

Lista de benefícios de cada plano;

Botões de assinatura;

Área para cadastro de e-mail;

Rodapé com links e informações da plataforma.

Objetivo acadêmico

Praticar a criação de cards, layouts em colunas, hierarquia visual,
botões e organização de informações, utilizando HTML e CSS.

------------------------------------------------------------------------------

🟣 Nível 3 --- Studio Form

Sobre o projeto

O **Studio Form** é um site institucional fictício de um estúdio
especializado em design, identidade visual e criação de experiências
para marcas.

Esse projeto possui uma proposta visual mais elaborada, utilizando
diferentes seções para apresentar os serviços, projetos e informações da
empresa.

Principais seções

Cabeçalho com navegação;

Seção principal (Hero);

Apresentação do estúdio;

Botão de chamada para ação;

Indicadores de projetos, clientes, prêmios e experiência;

Seção de projetos em destaque;

Identidade Visual;

Site Institucional;

Aplicativo;

Campanha;

Seção de contato;

Rodapé com navegação e informações.

Objetivo acadêmico

Aprimorar a construção de interfaces mais completas, trabalhando
composição visual, cards, seções institucionais, imagens, espaçamentos,
tipografia e identidade visual com HTML e CSS.

---------------------------------------------------------------------------------

🛠️ Tecnologias utilizadas

Os três projetos foram desenvolvidos utilizando apenas:

HTML5

CSS3

Não foram utilizados frameworks ou bibliotecas de JavaScript nesses
projetos.

---------------------------------------------------------------------------------

🎯 Objetivos dos projetos

O desenvolvimento dos projetos teve como principais objetivos:

Praticar HTML e CSS;

Melhorar a organização e estruturação de páginas web;

Desenvolver layouts modernos;

Praticar criação de componentes visuais;

Trabalhar cores, tipografia e espaçamentos;

Desenvolver páginas institucionais e comerciais;

Evoluir na criação de interfaces para web;

Aplicar na prática os conhecimentos estudados no curso.

----------------------------------------------------------------------------------

🎓 Contexto acadêmico

Projetos desenvolvidos para fins de aprendizado e prática acadêmica
durante o curso da Digital College.

Os projetos representam etapas diferentes de evolução no desenvolvimento
de interfaces web, indo de uma página institucional mais simples até uma
interface com maior quantidade de seções e elementos visuais.

---------------------------------------------------------------------------------

📌 Observação

Todos os nomes de empresas, marcas, serviços, preços e informações
apresentados nos projetos são fictícios ou utilizados exclusivamente
